# 💖 Interactive Proposal Website

A cute romantic interactive  website built using HTML, CSS and JavaScript.

This project includes fun animations, games and a sweet love note experience.

## ✨ Features
- Funny YES / NO proposal interaction
- Moving NO button
- Confetti animation
- Gift selection section
- Cute love quiz
- Final sweet letter page
- Background Bollywood music
- Fully responsive design
- Deployed online

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Vercel (deployment)
